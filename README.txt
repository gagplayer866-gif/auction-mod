BUILD THE JAR WITHOUT INSTALLING ANYTHING
1. Make a free GitHub account, create a new empty repository.
2. Upload ALL files in this folder (including the hidden .github folder) - drag the folder contents into "Add file > Upload files".
3. Open the Actions tab, wait for "build" to finish (~2 min).
4. Click the run, download "auctionmod-jar" under Artifacts, unzip it.
5. Put auctionmod-1.0.0.jar (not the -sources one) in .minecraft/mods with Fabric Loader + Fabric API for 1.21.4.

USE: hold an item, type /auction start 5k 60. Players bid in chat ("5k").
